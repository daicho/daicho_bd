# オタク年表

昔の記憶は結構あやふやです。

| 時期 | 出来事 |
| --- | --- |
| 2000年 | 生まれる |
| 2010年 | 友達にボカロを布教される（オタクの始まり） |
| 2010年 | ニコ動でボカロや歌ってみたを漁る |
| 2011年 | 「けいおん！」を布教され、アニメを見まくる |
| 2012年 | 「神のみぞ知るセカイ」にハマる |
| 2014年 | 「ラブライブ！」にハマり、スクフェスをめっちゃやる |
| 2016年 | 「灼熱の卓球娘」にハマる |
| 2017年 | 「けものフレンズ」にハマる |
| 2017年 | コミケ93に参加する（初めてのイベント参加） |
| 2018年 | VTuberにハマる（ときのそら、響木アオなど） |
| 2019年冬 | 「私に天使が舞い降りた！」にハマる |
| 2019年夏 | 「ソウナンですか？」にハマる |
| 2019年秋 | 「ライフル・イズ・ビューティフル」にハマる |
| 2021年冬 | 「ウマ娘 プリティーダービー Season 2」で泣く |
| 2022年秋 | 「Do It Yourself!! -どぅー・いっと・ゆあせるふ-」にハマる |
| 2023年春 | 「アイドルマスター シンデレラガールズ U149」にハマる |
| 2024年春 | 「ガールズバンドクライ」にハマる |
| 2024年春 | 「はなまきこもちぃ」にハマる |
| 2024/6/22 | 「大室家 dear friends」上映記念舞台挨拶に参加する<br>初めて声優を生で見る |
| 2024/7/5 | MyGO!!!!!とトゲナシトゲアリ「Avoid Note」が発表される<br>ここで初めてMyGO!!!!!の存在を知る |
| 2024年夏 | バンドリーマーの友達にAvoid Noteに誘われ、「トゲトゲが出るなら行ってみるかぁ」くらいの気持ちでOKする |
| 2024年夏 | Avoid Noteに応募するために、Poppin'Party×MyGO!!!!! 合同ライブ「Divide/Unite」のBlu-rayを買って見る<br>無路矢に衝撃を受ける |
| 2024年夏 | 「BanG Dream! It's MyGO!!!!!」を見る<br>何回も見る |
| 2024年秋 | 劇場版「BanG Dream! It's MyGO!!!!! 前編 : 春の陽だまり、迷い猫」を見る<br>何回も見る |
| 2024年秋 | 劇場版「BanG Dream! It's MyGO!!!!! 後編 : うたう、僕らになれるうた & FILM LIVE」を見る<br>何回も見る |
| 2024年冬 | ガルパを始める<br>Morfonicaにハマる |
| 2024/12/22 | MyGO!!!!! 7th LIVE「こたえなんてなくても」を配信で見る |
| 2025/1/12 | MyGO!!!!!×トゲナシトゲアリ「Avoid Note」に参加 |
| ～ | MyGO!!!!!をたくさん推す |
| 2026年2月 | 転職して新幹線が通ってるところに引っ越す |
